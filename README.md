# Pokemon memory game

This is a game app that tests your memory.

## Features

- Score tracker (Best and Current)
- Randomize images on every click
- Tracks which images have already been clicked
- Resets click state and curent score when a clicked image is clicked again

Checkout the live [Pokemon Memory Game](https://memory-card-eva01.vercel.app/)

This is a part of [The Odin Project](https://www.theodinproject.com/lessons/react-new-memory-card)
